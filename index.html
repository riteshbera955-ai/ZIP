Duplicate rule: SHA-256 checks exact file contents, not filenames. Renamed copies of the same PDF/JPG are detected. A visually identical PDF and JPG are not duplicates under exact-byte matching. New unique fingerprints are saved to the permanent SQLite database on Render's persistent disk. Other file types are ignored. Each ZIP allows up to 5,000 entries, 300 MB expanded supported content and 60 MB per individual file.
